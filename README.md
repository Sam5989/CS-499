# CS-499 Computer Science Capstone ePortfolio

## Overview

This repository contains my Computer Science Capstone ePortfolio for Southern New Hampshire University. The portfolio showcases my growth as a computer science student through enhancements to the Travlr Getaways full-stack web application.

Travlr Getaways is a travel management application that uses Angular for the front end, Node.js and Express for the back end, and MongoDB for data storage.

The project demonstrates improvements in software engineering, algorithms and data structures, and database design and implementation.

## Portfolio Contents

### Enhancement 1: Software Engineering and Design

This enhancement improves application security, validation, error handling, and code organization. Updates include more consistent authentication behavior, safer JWT handling, improved trip data validation, and clearer server-side error responses.

### Enhancement 2: Algorithms and Data Structures

This enhancement improves trip listing performance by introducing server-side pagination, searching, sorting, and result counting. Instead of loading the entire trip collection at once, the application retrieves the requested page of results.

### Enhancement 3: Databases

This enhancement improves database reliability and query efficiency through schema validation, data normalization, indexes, field selection, and more controlled database error handling.

## Running the Application

Running Travlr Getaways requires the appropriate development tools, project dependencies, and a configured MongoDB database.

### Prerequisites

- Node.js and npm
- MongoDB or an accessible MongoDB database
- Visual Studio Code or another code editor
- Postman, if you want to test API endpoints manually

### Setup

1. Clone or download this repository.
2. Navigate to the relevant Travlr project directory.
3. Install the Node.js dependencies using `npm install` in the appropriate application directories.
4. Configure the MongoDB connection using the project's expected configuration and environment variables.
5. Start the Express server using the start command defined in its `package.json`.
6. Start the Angular application using the appropriate command defined in its `package.json`.
7. Open the local front-end address displayed by Angular in your browser.

The exact commands and configuration depend on the original project structure. Consult the relevant `package.json` files and project configuration before starting the application.

**Important:** Do not commit database credentials, JWT secrets, or other private configuration values to this repository.
