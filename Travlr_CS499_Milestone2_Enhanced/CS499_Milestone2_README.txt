CS-499 Milestone Two - Travlr Getaways

This folder contains the Travlr Getaways technical artifact with the planned
Software Design and Engineering enhancement completed for Milestone Two.

Main enhanced files:
- app_api/controllers/authentication.js
- app_api/controllers/trips.js
- app_api/routes/index.js
- app_api/Models/users.js
- app_api/Models/seed.js
- app_admin/src/app/services/authentication.ts

The enhancement focuses on authentication and error handling, input validation,
safer JWT handling, removal of debugging output, clearer naming, and improved
separation of responsibilities.

The original project structure and application code are retained. Dependency
folders such as node_modules and the Git metadata folder are excluded from this
submission archive because they are generated/development files rather than
source artifacts.
